1. Overview

This responsive PHP/MySQL application presents a gym’s branches and membership packages. Visitors can register and sign in; members can create a membership plan by selecting its package, exercise focus, branch, start date, duration, and payment method. Plans and enquiries are persisted in MySQL. Each booking has a unique payment reference, and members can submit the transaction code from their receipt for manual administrator comparison. A submitted code does not automatically prove payment; the plan stays pending until verified.

2. Implemented features

  • Home, About, Membership, Contact, Register, Login, Dashboard, and Logout pages with shared navigation.
  • Responsive CSS using Grid, Flexbox, and mobile breakpoints; light/dark theme toggle.

3. Database design

The schema in database.sql defines four tables. Bookings link to users and plans by foreign keys; plan prices are read from the plans table.

TablePurpose and key links
usersMember profile, unique email/username, password hash.
plansPackage name, monthly price, duration, description.
bookingsUser and plan foreign keys; branch, membership dates, focus, months, total, payment state, unique reference, submitted receipt transaction code.
messagesContact form submissions.

Passwords are stored using PHP password hashing. The contact messages table is independent and records enquiries.
